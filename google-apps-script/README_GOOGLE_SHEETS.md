# 📘 คู่มือเชื่อมต่อ Google Sheets ฟรี 100%
### โครงการงานวิ่งเปิดโลกทะเล เกาะยาวใหญ่ ๒๕๗๐ (เทศบาลตำบลพรุใน)

ระบบนี้ทำให้:
1. ข้อมูลนักวิ่งทั้งหมดจะวิ่งตรงเข้า **Google Sheets** ของเทศบาลสดๆ ทันที
2. รูปภาพสลิปที่ผ่านการย่อขนาดแล้ว จะถูกเซฟเข้า **Google Drive** ของเทศบาลในโฟลเดอร์ `KohYaoRun_Slips_2570` อัตโนมัติ
3. รองรับการใช้งานฟรี 100% ตลอดชีพ ไม่ต้องเสียค่าเซิร์ฟเวอร์แม้แต่บาทเดียว

---

## 🚀 ขั้นตอนการติดตั้ง (ทำครั้งเดียวเสร็จใน 3 นาที)

### ขั้นตอนที่ 1: สร้าง Google Sheets แผ่นใหม่
1. ล็อกอินเข้า Google Drive ของเทศบาล หรือบัญชี Google ของคุณ
2. กดปุ่ม **+ ใหม่ (+ New)** ➔ เลือก **Google ชีต (Google Sheets)**
3. ตั้งชื่อไฟล์ด้านซ้ายบนว่า: `งานวิ่งเปิดโลกทะเล 2570`

---

### ขั้นตอนที่ 2: นำโค้ด Apps Script ไปวาง
1. ที่แถบเมนูด้านบนของ Google Sheets ไปที่เมนู:  
   **ส่วนขยาย (Extensions)** ➔ **Apps Script**
2. ลบโค้ดเดิมในหน้าจอออกให้หมด
3. เปิดไฟล์ `google-apps-script/Code.gs` ในเครื่องของคุณ แล้ว**คัดลอก (Copy) โค้ดทั้งหมด**มาวางลงใน Apps Script
4. กดปุ่ม **บันทึก (รูปแผ่นดิสก์ 💾 หรือกด Ctrl + S)**

---

### ขั้นตอนที่ 3: เผยแพร่เป็น Web App (Deploy)
1. กดปุ่มสีน้ำเงิน **ทำให้ใช้งานได้ (Deploy)** ที่มุมขวาบน ➔ เลือก **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
2. คลิกรูปฟันเฟือง ⚙️ ข้าง "เลือกประเภท" ➔ เลือก **เว็บแอป (Web app)**
3. ตั้งค่าดังนี้:
   - **คำอธิบาย (Description):** `Koh Yao Run API v1`
   - **เรียกใช้ในฐานะ (Execute as):** `ฉัน (อีเมลของคุณ)`
   - **ผู้มีสิทธิ์เข้าถึง (Who has access):** **ทุกคน (Anyone)** *(สำคัญมาก! เพื่อให้นักวิ่งส่งสลิปผ่านหน้าเว็บได้)*
4. กดปุ่ม **ทำให้ใช้งานได้ (Deploy)**
5. Google จะขอสิทธิ์เข้าถึง ให้กด:
   - *ตรวจสอบสิทธิ์ (Authorize access)*
   - เลือกบัญชี Google ของคุณ
   - กด *ขั้นสูง (Advanced)* ➔ กด *ไปที่ (ไม่ปลอดภัย) / Go to Untitled project (unsafe)*
   - กด *อนุญาต (Allow)*
6. เมื่อเสร็จแล้ว จะได้รับ **URL เว็บแอป (Web App URL)** เช่น:  
   `https://script.google.com/macros/s/AKfycbx.../exec`
7. **คัดลอก (Copy) URL นี้ไว้!**

---

### ขั้นตอนที่ 4: นำ URL ไปวางในหน้าเว็บ
เปิดไฟล์ `js/store.js` ในโฟลเดอร์เว็บ แล้วนำ URL ที่ได้มาใส่ในตัวแปร `GOOGLE_SCRIPT_URL` ที่บรรทัดแรก:

```javascript
const GOOGLE_SCRIPT_URL = "https://script.google.com/macros/s/AKfycbx.../exec";
```

**เสร็จสิ้น!** เว็บไซต์จะเชื่อมต่อกับ Google Sheets และ Google Drive ของคุณทันทีครับ 🎉
